# AWS service icons

These unmodified SVGs come from the July 31, 2026
[AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) package.
They represent Amazon Bedrock, Amazon SageMaker AI, Amazon EC2, Amazon EKS and
AWS Batch. SageMaker AI uses its own service icon, not the separate SageMaker
analytics platform icon.

The application bundles the artwork locally and preserves the official colors
in both themes. It does not load icons from an external CDN.
